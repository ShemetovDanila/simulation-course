### Моделирование случайных событий (GUI)

**Часть 1:**  
Приложение «Скажи “да” или “нет”».

**Часть 2:**  
Приложение «Шар предсказаний» (Magic 8-Ball).


## Описание

Приложение демонстрирует моделирование случайных событий с неравномерными вероятностями на платформе Windows Forms. В основе реализации лежит самописный генератор случайных чисел, использующий мультипликативный конгруэнтный метод без применения встроенного `System.Random`.

Выбор случайного исхода выполняется методом последовательного вычитания вероятностей до момента попадания в отрицательную область. Предусмотрена автоматическая нормировка: если сумма заданных вероятностей не равна единице, выполняется их пересчёт. Для второй части задачи список классов предварительно сортируется по убыванию вероятности с помощью пузырьковой сортировки.
