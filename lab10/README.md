# Имитационная модель СМО M/M/N/(N+M)

Моделирование многоканальной системы массового обслуживания с ограниченной очередью методом **следующего события**.

## Описание модели

Система реализует СМО M/M/N/M:

- входящий поток — пуассоновский с интенсивностью **λ**
- время обслуживания — экспоненциальное с параметром **μ**
- **N** параллельных приборов, очередь ёмкостью **M**
- заявка получает отказ, если заняты все N приборов и все M мест в очереди

## Параметры запуска

| Параметр | Значение | Описание |
|---|---|---|
| λ | 15 | Интенсивность поступления заявок |
| μ | 5 | Интенсивность обслуживания одного прибора |
| N | 5 | Число параллельных приборов |
| M | 10 | Ёмкость очереди |
| Событий | 100 00 | Количество шагов моделирования |
| Seed | ticks | Зерно генератора |

## Собираемая статистика

На каждом шаге (до смены состояния) накапливаются взвешенные суммы:

```
stateDurations[x+y] += timeStep   // время в каждом состоянии → P[k] = stateDurations[k] / T
totalBusyTime        += x·timeStep // → среднее число занятых приборов
totalQueueTime       += y·timeStep // → средняя длина очереди
```

## Выходные метрики

- **P[k]** — эмпирическая вероятность нахождения k заявок в системе
- **avgBusyServers** = totalBusyTime / T
- **avgQueueLength** = totalQueueTime / T
- **P_отк** = rejected / totalRequests

Гистограмма P[k]: зелёные столбцы — состояния без очереди (k ≤ N), коралловые — состояния с очередью (k > N).

## Генератор случайных чисел

Мультипликативный конгруэнтный генератор:

```
x = (c · x) mod m,   m = 2³¹ − 1,   c = m/2000 + 3
```

Равномерное U(0,1) преобразуется в экспоненциальное методом обратной функции:

```
X = −ln(1 − U) / rate
```

## Вывод

При моделировании системы M/M/5/10 с параметрами λ = 15 и μ = 5 коэффициент загрузки составил ρ = λ/μ = 3,0 — это означает, что в среднем каждый прибор «хочет» обрабатывать в 3 раза больше заявок, чем успевает. Несмотря на это, система справляется: 5 параллельных приборов суммарно дают пропускную способность 5μ = 25, что перекрывает входящий поток λ = 15.
Из 100 000 заявок отказ получили лишь 41 (P_отк = 0,0004). Это говорит о том, что очередь на 10 мест оказалась достаточным буфером — случайные пики входящего потока гасятся накопителем, не доходя до отказов. Средняя длина очереди при этом составила всего 0,35 заявки, то есть очередь большую часть времени практически пуста.
При увеличении числа моделируемых событий результаты стабилизируются и сходятся к теоретическим значениям — это подтверждает корректность модели. При уменьшении N или увеличении λ картина меняется: очередь растёт, вероятность отказа увеличивается, а доля занятости приборов стремится к 100%. Введение же дополнительных приборов или расширение очереди M, напротив, снижает P_отк вплоть до нуля при достаточном запасе ресурсов.
