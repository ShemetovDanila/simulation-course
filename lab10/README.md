### Система массового обслуживания M/M/N/∞
Моделирование многоканальной СМО с бесконечной очередью

Использовать метод следующего события для моделирования системы массового обслуживания M/M/N/N, где:
- простейший входящий поток с интенсивностью λ
- время обслуживания на каждом приборе распределено экспоненциально с параметром μ
- $N$ параллельных обслуживающих приборов
- очередь неограниченной емкости (заявка встает в очередь, если все $N$ приборов заняты)

- определить эмпирические вероятности состояний $P_k$ (нахождение $k$ заявок в системе)
- вычислить среднее число занятых приборов и среднюю длину очереди
- визуализировать распределение вероятностей состояний системы на гистограмме
- сделать вывод о характере работы многоканальной СМО

## Используемые параметры

| Параметр | Значение | Описание |
|---|---|---|
| λ | 5 | Интенсивность поступления заявок |
| μ | 2 | Интенсивность обслуживания одного прибора |
| N | 10 | Количество параллельных приборов |
| M | 10 | Количество мест в очереди |
| Количество заявок | 10000 | Число обрабатываемых событий цикла |
| Seed | ticks | Зерно мультипликативного генератора |

## Выводы

1. **Анализ характеристик многоканальной системы.** Переход от одноканальной СМО к многоканальной архитектуре с бесконечной очередью ($M/M/N/\infty$) позволил детально оценить динамику распределения нагрузки. При заданных параметрах среднее число занятых приборов составляет около 1.58 из 3 доступных, что обеспечивает стабильную работу системы без бесконечного лавинообразного роста очереди, так как суммарная интенсивность обслуживания ($N \cdot \mu = 2.4$) превышает интенсивность входящего потока ($\lambda = 1.5$).

2. **Распределение вероятностей состояний.** Накопление системного времени пребывания в каждом из состояний (от $P_0$ до $P_k$) позволило построить эмпирическую гистограмму распределения. Разделение состояний на графике на "свободные каналы" ($k \le N$) и "растущая очередь" ($k > N$) наглядно демонстрирует баланс загруженности системы и подтверждает устойчивость исследуемого марковского процесса.
