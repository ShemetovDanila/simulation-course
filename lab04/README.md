### Базовый датчик случайных чисел

**Задание:**
- реализовать базовый датчик случайных чисел;
- вычислить выборочные среднее и дисперсию:
  - для реализованного датчика;
  - для встроенного генератора языка программирования;
- размер выборки — **100 000 значений**;
- сравнить результаты с теоретическими;
- сделать вывод.

# Базовый датчик случайных чисел

Реализованы и сравнены три генератора случайных чисел на отрезке [0, 1):

1. **Мультипликативный конгруэнтный метод** — `x = (c * x) % m`, нормируется делением на `m`
2. **Метод середины квадрата** — возводим зерно в квадрат, берём средние цифры
3. **Встроенный `rand()`** из стандартной библиотеки C++

Начальное зерно вводится пользователем. На выборке из **100 000 чисел** считаются среднее и дисперсия.

## Результаты (зерно = 123456)

| Метод | Среднее | Дисперсия |
|---|---|---|
| Мультипликативный | 0.500068 | 0.0831467 |
| Середина квадрата | 0.509972 | 0.0500183 |
| Встроенный `rand` | 0.500183 | 0.0830171 |
| **Теория U[0,1)** | **0.5000** | **0.0833** |

## Вывод

Мультипликативный метод и встроенный `rand` хорошо совпадают с теорией. Метод середины квадрата заметно хуже — он склонен к вырождению и имеет короткий период.
